# Poké Champions 简繁汉化与搜索修正脚本

这是一个为宝可梦对战数据网站 **[Poké Champions](https://victorpoke-champions.com/)** 编写的 Tampermonkey（油猴）脚本。它能够无缝将网站的繁体中文界面翻译为简体中文，同时完美支持在搜索框输入简体中文进行筛选和搜索。

## ✨ 功能特点

1. **精细汉化**：内置全世代 **2,400+ 个** 官方宝可梦专有名词双向字典，精准翻译宝可梦名称、招式、特性、道具和性格，避免出现普通翻译软件的过度翻译或翻译差错。
2. **搜索无忧**：在搜索框中直接输入**简体中文**（如“喷火龙”、“守住”），脚本会自动将输入隐式转换为繁体中文以触发 Vue 底层的数据过滤，完美解决简中搜索失效的问题。
3. **极简轻量**：没有冗余的 UI 注入，仅在启用本脚本时自动生效。可以通过点击浏览器插件图标随时开启/关闭，稳定可靠，不会干扰网站原有的路由和事件监听。

---

## 🚀 安装步骤

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 点击 Tampermonkey 图标，选择 **“添加新脚本”**。
3. 复制本项目中的 [`script.user.js`](./script.user.js) 文件的全部内容，粘贴到编辑器中。
4. 按 `Ctrl + S` (或 `Cmd + S`) 保存脚本。
5. 刷新 [Poké Champions](https://victorpoke-champions.com/zh-TW) 网站即可开始享受流畅的简体中文体验！

## 🛠️ 自定义与字典修改

如果未来游戏版本更新了新的宝可梦或道具，或者发现有个别词条翻译不准确，您可以直接在脚本中方便地编辑和增补：

1. 打开 Tampermonkey 面板，点击编辑该脚本。
2. 在脚本顶部（大约第 17 行附近）有两个核心字典结构：
   - **`pokeDictT2S`**：用于界面元素从**繁体转为简体**。格式为 `"繁体":"简体"`。
   - **`pokeDictS2T`**：用于搜索栏输入时将**简体转为繁体**。格式为 `"简体":"繁体"`。

```javascript
// 示例
const pokeDictT2S = {
    "阿羅拉的樣子": "阿罗拉的样子",
    // 在这里添加您想要自定义的繁转简词条...
};

const pokeDictS2T = {
    "阿罗拉的样子": "阿羅拉的樣子",
    // 在这里添加您想要自定义的简转繁搜索词条...
};
```

*注：脚本会优先匹配这两个字典中的专业术语，剩余的常规文本会自动采用内置的高效翻译引擎进行智能转换，确保翻译质量最优。*
